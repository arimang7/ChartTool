# 프로젝트 사용법 (Usage Guide)

## 1. 사전 준비 사항 (Prerequisites)

- **Java**: JDK 21 이상이 설치되어 있어야 합니다.
- **Python**: 3.10 이상의 Python 환경이 필요하며, 프로젝트 상위 디렉토리의 `.venv`에 설치되어 있어야 합니다.
  - 필요한 라이브러리: `yfinance`, `pandas`
- **API 키 발급**:
  - **Google Cloud Console**: OAuth2 클라이언트 ID 및 보안 비밀번호 발급 (Google 로그인용).
  - **Google AI Studio**: Gemini API Key 발급.
  - **Telegram**: BotFather를 통해 봇 생성 및 `bot-token`, `chat-id` 획득.

## 2. 설정 (Configuration)

`src/main/resources/application.yml` 파일에서 다음 항목들을 설정합니다.

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          google:
            client-id: YOUR_CLIENT_ID
            client-secret: YOUR_CLIENT_SECRET

app:
  gemini:
    api-key: YOUR_GEMINI_API_KEY
  telegram:
    bot-token: YOUR_BOT_TOKEN
    chat-id: YOUR_CHAT_ID
  python:
    path: ../.venv/Scripts/python.exe # 운영체제에 맞는 python 실행 경로
    script-path: ../yfinance_adapter.py
```

## 3. 실행 방법 (Running the Application)

### 빌드 및 실행 (CLI)
```bash
# 빌드
mvn clean install

# 실행
mvn spring-boot:run
```

### IDE에서 실행
- `com.charttool.ChartToolApplication` 클래스의 `main` 메서드를 실행합니다.

## 4. 주요 기능 사용법

1. **메인 접속**: 브라우저에서 `http://localhost:8080`에 접속합니다.
2. **로그인 (선택)**: 우측 상단의 Google 로그인 버튼을 통해 로그인하거나 게스트로 이용합니다.
3. **티커 검색**: 검색창에 종목 코드(예: `AAPL`, `TSLA`, `NVDA`)를 입력하고 검색합니다.
4. **차트 확인**: 해당 종목의 주가 차트, RSI, 볼린저 밴드 지표를 확인합니다.
5. **AI 분석**: 'AI 분석' 버튼을 클릭하여 Gemini가 분석한 상세 리포트와 매수/매도 타점을 확인합니다.
6. **텔레그램 알림**: 생성된 AI 리포트 하단의 'Telegram으로 전송' 버튼을 눌러 본인의 텔레그램으로 전송합니다.

## 5. API 명세

- `GET /?ticker={ticker}`: 메인 페이지 및 기본 분석 데이터 로드.
- `GET /api/ai-analysis?ticker={ticker}`: Gemini AI 분석 리포트 생성 (JSON).
- `POST /api/send-telegram`: AI 리포트를 텔레그램으로 전송.
  - Body: `{"ticker": "...", "report": "..."}`
