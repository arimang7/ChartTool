## 주요 구성 요소 설명

### 1. 백엔드 (Java/Spring Boot)
- **StockService**:
    - 외부 Python 스크립트(`yfinance_adapter.py`)를 호출하여 주식 데이터를 수집합니다.
    - `ta4j` 라이브러리를 사용하여 RSI, 볼린저 밴드, 거래량 급증 등을 분석합니다.
    - 하모닉 패턴(Harmonic Patterns) 탐지 로직을 포함합니다 (현재 모킹 구현).
    - Google Gemini API를 통해 기술적 지표와 뉴스를 바탕으로 투자 전략 리포트를 생성합니다.
    - Telegram Bot API를 사용하여 분석 리포트를 사용자에게 전송합니다.
- **StockController**:
    - `/`: 홈 화면 및 특정 티커의 분석 데이터 조회.
    - `/api/ai-analysis`: Gemini AI를 통한 상세 분석 리포트 생성 API.
    - `/api/send-telegram`: 생성된 리포트를 텔레그램으로 전송하는 API.
- **SecurityConfig**:
    - Google OAuth2 로그인을 지원하며, 로그인하지 않은 게스트 사용자도 서비스 접근이 가능하도록 설정되어 있습니다.

### 2. 데이터 수집 (Python)
- **yfinance_adapter.py** (상위 디렉토리 위치):
    - `yfinance` 라이브러리를 사용하여 Yahoo Finance로부터 주가 이력 및 뉴스 데이터를 가져와 JSON 형식으로 백엔드에 전달합니다.

### 3. 프론트엔드 (Thymeleaf/HTML)
- **index.html**:
    - Highcharts 또는 유사한 라이브러리를 사용하여 주가 차트와 기술적 지표를 시각화합니다.
    - AI 분석 요청 및 텔레그램 전송 버튼을 제공합니다.
